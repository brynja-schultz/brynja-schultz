## Featured Projects

### Evaluating LLMs for Legal Question Answering
Evaluated BERT-based models on legal question-answering tasks using the CaseHOLD dataset.

**Key work:**
- Compared Legal-BERT, Custom-Legal-BERT, and BERT-Double on legal reasoning examples.
- Designed a Weighted Correctness Score using BERTScore and geometric mean aggregation.
- Focused on confidence calibration, model reliability, and weaknesses not captured by traditional accuracy metrics.
- Incorporated practitioner feedback to better align evaluation methods with high-stakes legal informatics use cases.

**Skills:** NLP, BERT, model evaluation, Python, BERTScore, ML metrics

### Cloud-Based Media Archiving & Data Engineering
Built and maintained an AWS S3-based workflow to digitize, organize, and preserve 1,000+ hours of legacy analog media.

**Key work:**

- Used metadata tagging and storage-tiering practices to improve organization and retrieval.
- Managed large-scale digital archiving across heterogeneous legacy media sources.

**Skills:** AWS S3, cloud storage, metadata, data organization, long-term preservation
